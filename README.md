## 🚀 Featured Projects

### 🛡️ [CVE Risk Prioritization Engine (CRPE)](https://github.com/neakvigran/CVE-Risk-Prioritization-Engine)
**Cybersecurity Research | Vulnerability Assessment | Network Security | Python**

An ongoing cybersecurity project that I am developing to analyze and prioritize vulnerabilities based on vulnerability intelligence, asset information, and network relationships.

The goal is to understand how vulnerabilities across connected systems may contribute to potential attack paths and how this information can help prioritize remediation.

**Current Features:**
- Collects vulnerability information from NVD, FIRST EPSS, and CISA KEV.
- Implements CVSS-based and context-aware vulnerability prioritization.
- Provides explanations for vulnerability scores and rankings.
- Manages assets, network interfaces, services, and security zones.
- Analyzes network connectivity using allow, deny, and unknown decisions.
- Supports historical analysis, JSON/CSV reports, and database backup and recovery.

**Tech Stack:** Python, FastAPI, SQLite, SQLAlchemy, NetworkX, Pydantic, Typer, pytest.

**Current Progress:** Version 0.3.0. Milestones 1–3 and M4.1–M4.2 are completed. Currently preparing topology snapshots and multi-hop reachability analysis.

**Future Direction:** Attack-path analysis and remediation impact prioritization.
